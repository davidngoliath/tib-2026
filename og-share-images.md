# OG Share Images

This document lists the current Open Graph share image used for each page.

Note: canonical page URLs and absolute image URLs are generated from the site URL in [lib/seo.ts](lib/seo.ts#L4-L24). If `NEXT_PUBLIC_SITE_URL` is set at runtime, that domain will be used instead of the fallback `https://tib-2026.vercel.app`.

## Default OG image

Pages that do not set a custom `imagePath` use this default image:

- Default image path: [public/images/home/youth-portrait.jpg](public/images/home/youth-portrait.jpg)
- Default absolute image URL: https://tib-2026.vercel.app/images/home/youth-portrait.jpg
